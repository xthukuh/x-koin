# x-koin

xKoin is a decentralized hybrid mesh for Kenya: a box on a building's mains carries internet over the existing wiring (PLC) and over LoRa where the wiring ends. Every byte on the wide network is metered and settled off-chain in state-channel tickets, redeemed on an L2, and bridged to and from M-Pesa (Daraja) and Equitel (Jenga). The invention and the repository are Martin Thuku's ([github.com/xthukuh](https://github.com/xthukuh), [thuku.dev](https://thuku.dev)).

Trust model, stated honestly: the peer layer is zero-trust, no peer must trust any other peer (`protocol/spec.md` section 7, enforced in Python, Solidity and C). The fiat boundary has named trusted parties for the MVP (kiosk root key, bridge hot wallet, owner keys) with a removal roadmap in spec section 8. Payback figures in the financial model are conditional on per-unit pricing clearing measured backhaul cost; do not quote them without that check.

## Quick start: the site

Node 22 or newer. The site image builds on `node:22-alpine`; this Windows host runs Node 26.4.0 and builds the same tree.

    npm --prefix web ci
    npm run dev:web
    # http://localhost:5173

That is the whole loop for page work. Nothing is generated by hand before it: the only prestep is `scripts/build-sitemap.mjs`, which the `predev` script runs for you.

## Windows host notes

These are the specifics that cost time when they are rediscovered.

    python -m venv .venv                       # Python 3.14.6 in .venv/
    export PATH="$HOME/.foundry/bin:$PATH"     # Foundry 1.5.1-stable
    PYTHON=.venv/Scripts/python.exe MAKE=mingw32-make scripts/bootstrap.sh

- Always call `.venv/Scripts/python.exe` with a script path. The bare Windows `python` alias with no script hangs and spins the CPU.
- `make` is `mingw32-make` here (GNU Make 4.2.1, gcc 6.4.0 from MinGW-w64).
- Foundry lives in `~/.foundry/bin` and is not on the default PATH.
- WSL Ubuntu-20.04 on this host is unusable: no DNS, and sudo wants a password. Use PowerShell or Git Bash.
- Docker Desktop 29.2.1 works.
